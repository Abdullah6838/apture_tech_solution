# 🛒 API Product Data Cleaner & CSV Exporter

A Python 🐍 project that fetches product data from an API, cleans and validates it, calculates statistics 📊, and exports the cleaned data to a CSV file 📄.

## ✨ Features

- 🌐 Fetch product data from API
- 🧹 Clean and validate data
- 🔄 Remove duplicate products
- ❌ Remove invalid records
- 💰 Validate product prices
- 📝 Handle missing titles
- 🏷️ Clean product categories
- ⭐ Handle missing ratings
- 📊 Calculate product statistics
- 🏆 Find highest price
- 🔻 Find lowest price
- 💵 Calculate average price
- 📦 Calculate category statistics
- 📄 Export data to CSV
- ⚠️ Handle API errors

## 🛠️ Requirements

- 🐍 Python 3.7+
- 📦 `requests` library

## 📥 Installation

Install the required package:

```bash
pip install requests
```
<br>

> 💡 `cleaned_products.csv` is automatically created after the program runs successfully.
