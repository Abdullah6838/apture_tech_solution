# 📚 Student Record System

A simple **Python-based Student Record Management System** that stores student information in a CSV file 📄.

## ✨ Features

- ➕ Add a new student
- 👀 View all students
- 🔍 Search for a student
- ✏️ Update student record
- 🗑️ Delete student
- 🆔 Automatically generate student IDs

## 🛠️ Requirements

- 🐍 Python 3.x
- 📦 No external libraries required

## 🚀 How to Run

1. 💾 Save the code as `main.py`
2. 📄 The program uses `data.csv` for storing records
3. ▶️ Run the program:

```bash
python main.py
